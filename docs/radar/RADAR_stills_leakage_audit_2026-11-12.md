# Doppler measurement leakage audit: PR #47

**Decision: keep the Doppler stream disabled for research training.** The implementation is useful scaffolding, but it does not yet satisfy its proposed leakage gate. Synthetic counterexamples demonstrate that answer-bearing pixels and metadata can reach model inputs. Their frequency and influence in MHI images remain unmeasured.

Audit date: November 12, 2026. Reviewed [PR #47](https://github.com/HeartWise-AI/EchoJEPA/pull/47) at `3aa9a1512c3a32aada9e532edeabdc623895ea2f`, against stacked base `41d61e0156375b3b1250af8964516e9b6eae6a4d` on `radar/v0_pipeline`, not against main. This includes Charlotte Chen's `f555dc6` and subsequent `3aa9a15`. The [Notion design](https://app.notion.com/p/4150855e87b681dbac00dd7cf68acd2b) was read in its November 11, 14:06 UTC version. Its overlap rates, approximately 16% overall and 75% for Philips, are reported source findings, not independently reproduced measurements.

No governed images, patient tables, remote clinical storage, pretrained weights, or GPUs were accessed. New tests use invented identifiers, arrays and CPU tensors. No production code or default configuration is changed by this audit. No merge or training authorization is implied.

## Findings that affect enablement

### 1. P1: Sanitization does not remove all answer-bearing geometry

`overlay_mask` detects RGB chroma above 40, dilates that mask, and optionally exempts pixels matching the vendor tint. White/grey pixels never seed that mask. Tint-matched overlays are exempt too. A low overlay fraction is therefore not evidence of a clean image. The 20% rejection rule protects against erasing a tinted spectrum; it is not a leakage test. [Preprocessing, lines 80–136](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/src/datasets/still_preprocess.py#L80-L136).

Executed counterexamples: eight positions each of white, grey and tint-matched calipers survive into the 224-pixel encoder input. A fixed threshold/row-count rule recovers all 24 positions with zero pixel error, with zero overlay pixels reported as masked. White/grey numeric annotations also survive. These are deliberately constructed counterexamples, not trained-model accuracy or estimates of real-image prevalence. With the supplied velocity calibration, surviving vertical caliper positions could encode a measurement directly. Traced envelopes can similarly expose operator-chosen integration geometry.

The manifest only collects the measurement table's `x0,y0,x1,y1` boxes; it does not discover missing value boxes. A synthetic numeric value beyond the four-pixel label padding survives completely (208 changed pixels retained). Supplying both label and value boxes removes it on the uniform-background positive control. The known value-box gap and white/grey gap are confirmed, rather than presented as newly discovered documentation omissions. [Box construction, lines 143–161](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/data/build_still_manifest.py#L143-L161).

**Required remedy:** preserve label AND value boxes from extraction, use a detector or exclusion policy covering achromatic and tint-matched calipers/traces, and quarantine cases where removing an annotation would destroy the relevant waveform. Validate anti-aliasing, compression, scaling and each vendor layout. Grayscale conversion after chromatic masking cannot remove an achromatic annotation.

### 2. P1: Masking can create a measured-status and geometry shortcut

Each detected box is replaced with one median colour from its surrounding ring. Applying the same function to every image does not apply the same intervention: measured images have different boxes, lengths and positions. On a textured spectrum, the fill leaves a flat rectangle. Inpainting can leave additional footprints, although the present executable proof concerns median-filled text boxes. [Box fill, lines 44–68](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/src/datasets/still_preprocess.py#L44-L68).

Executed evidence: on 16 paired synthetic spectra that differ only by box application, a fixed local-variance rule distinguishes all 32 processed images. The paired difference recovers all 16 padded box bounding rectangles. The image-only rule scans for a low-variance patch and receives no box coordinates or paired control. This is a proof of a residual footprint on these noise-texture fixtures, not a validated measured-versus-unmeasured classifier on MHI data, which may have naturally uniform regions. Neither the real effect size nor target prediction from those footprints has been established.

**Required remedy:** test box/mask-only features and residual geometry, as well as pixels and frozen tokens. Develop masking on a development cohort, then freeze it before the audit. Do not enlarge boxes indiscriminately until classification becomes difficult: removing waveform information can make both the task and the leakage probe fail.

### 3. P1: The value-as-input guard is syntactic, and EchoNet provenance is unverified

`StillSource` refuses a conditioning column only when it is named in `target_columns` or begins `y_`. A numeric alias can carry the exact same measurement or a deterministic relative. `LEAK_GROUPS` is declared but never consumed by a validation path. Executed evidence passes `raw_maxpg=4*Vmax²` through `still_cond`, from which the target is recovered exactly. A deliberately target-correlated synthetic `n_rows` column also passes. This does not show that actual row counts determine MHI measurements or that the example config uses either column. [Input guard, lines 67–100](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/src/datasets/radar_stills.py#L67-L100); [declared groups](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/data/build_still_manifest.py#L70-L83).

The documented opt-in configuration does include EchoNet predicted Vmax/confidence/presence. `add_echonet` joins these by PNG path without requiring the model checkpoint, input preprocessing, training cohort or fold provenance. Heat-map content hashing now works, but content identity does not establish independence from the labels. EchoNet could reintroduce information read from an unmasked screen even if RADAR's own image is sanitized. This path is an unverified possibility, not proof that the existing EchoNet predictions are contaminated. [EchoNet join, lines 232–245](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/data/build_still_manifest.py#L232-L245).

**Required remedy:** allowlist inference-available features with provenance and units, prohibit measured or report-derived quantities and aliases, and enforce target-family dependencies. Keep EchoNet scalars AND heat maps disabled until their sanitized inputs, checkpoints and disjoint/out-of-fold training lineage are verified. An independently trained model applied to inference-available images is a legitimate ensemble input; report that arm as an ensemble, with an EchoNet-only baseline.

**Ablation caveat:** `model.stills.cond: false` disables scalar conditioning in the pooler only. Measurement heads still receive every configured conditioning column. For a true scalar-free arm, empty `data.stills.cond_columns`; disabling heat-map bias alone also leaves EchoNet scalars enabled. [Model assembly, lines 274–293](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/evals/radar_frozen/train.py#L274-L293).

### 4. P1: Training does not enforce a preprocessing or leakage-audit gate

Training consumes precomputed still tokens. It checks encoder compatibility but never requires proof that `prepare_still` ran, that its parameters were approved, or that any leakage audit passed. Matching encoder records with missing preprocessing or `preprocess="unmasked"` are accepted by the compatibility check. Both caches without encoder provenance are also accepted as synthetic caches without a production/synthetic distinction. The still cache writer and EchoNet runner are explicitly outside this PR. [Training assembly, lines 455–477](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/evals/radar_frozen/train.py#L455-L477); [encoder check](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/src/datasets/radar_stills.py#L41-L62).

The approved normality-policy checks for A2/A3 are separate. They do not certify pixel sanitization; A0/A1 can use the new stream without a leakage approval artifact. A fingerprint is valuable for reproducibility but can faithfully identify an unsafe input.

**Required remedy:** add a training preflight that refuses research stills unless a reviewed audit artifact binds the exact preprocessing implementation/parameters, extraction schema, source manifest, split manifest, encoder, still-token cache and optional EchoNet assets. Verify token contents against the cache index before qualification. Changing any bound artifact invalidates approval. Keep exceptions confined to explicit synthetic tests.

### 5. P1: Unmeasured inference lacks an independent cohort/routing path

The manifest starts from measurement rows, not a complete inventory of measured and unmeasured stills. A PNG absent from that table cannot appear in the output. `still_tag` and `still_type` are derived from the OCR measurement's structure/quantity; they affect bag selection, structure eligibility and learned type embeddings. These inputs describe the operator's measurement workflow. A truly unmeasured image cannot simply be assumed to have them. Untagged images without targets are dropped, while untagged images with targets can remain for measurement heads. [Manifest mapping](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/data/build_still_manifest.py#L106-L161); [selection](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/src/datasets/radar_stills.py#L91-L99).

An externally constructed table with valid inference-time tags can be consumed, so this is not a claim that `StillSource` categorically forbids unmeasured stills. What is missing is the inventory, independent tag assignment, measured-status audit field and qualification workflow. The zero-shot evaluator checks still-trained checkpoints correctly after Charlotte's fixes, but it evaluates structure/text similarity, not decoded per-still measurement-head accuracy. It also requires a nonempty clip table. Thus the proposed clean head evaluation is still additional work. [Evaluation, lines 418–437](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/evals/radar_frozen/zero_shot_eval.py#L418-L437).

**Required remedy:** enumerate all eligible Doppler stills before OCR success filtering; retain measured/unmeasured status for audit stratification only. Route them using acquisition metadata or a separately validated image classifier available before measurement. Prove that removing all targets and OCR measurement labels leaves sample membership and model inputs unchanged. Add a measurement-head evaluator on genuinely unmeasured stills.

### 6. P1 under identity conflicts: Split inheritance needs stronger reconciliation

Existing controls are useful: all studies of a consistent canonical patient inherit one split; contradictory splits for that patient are rejected; the caption builder checks patients across the extended still cohort; evaluation includes still-only training study IDs. These controls are not the old, resolved overlap omission.

Two new synthetic counterexamples expose remaining prerequisites. First, when `splits.patient_id` conflicts with `metadata.mrn`, `assign_splits` trusts the former without reconciliation. A later study of the same canonical patient can be hashed into training while the earlier study is in test. Second, a folder with one study UID but two different MRNs silently retains the first MRN. Both unsafe paths were executed with invented identifiers. [Folder join](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/data/build_still_manifest.py#L176-L196); [split assignment](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/data/build_still_manifest.py#L208-L229).

These fixtures do not prove that MHI contains conflicting identities. A correctly invoked caption patient audit with a complete canonical PACS map can catch the cross-split example. That is a conditional downstream protection, not a reason for the manifest builder to accept ambiguity. Training does not itself require full patient reconciliation, and evaluation's optional group check only covers training studies present in the label file. The caption build record's still-table digest is not checked by `check_caption_build` against the supplied training still table. [Caption record checks](https://github.com/HeartWise-AI/EchoJEPA/blob/3aa9a1512c3a32aada9e532edeabdc623895ea2f/src/datasets/radar_study_dataset.py#L254-L272).

**Required remedy:** reconcile all study/patient mappings, reject unknown/conflicting identities, validate the final union of clips, stills and reports by patient, and bind that audit to the exact manifests loaded. Audit repeated studies, duplicate pixels and measured/unmeasured exports of the same acquisition together. The proposed 2025 holdout is not enforced by the hashing code; reserve it explicitly after resolving patient overlap across years. Document possible patient exposure in encoder pretraining and upstream models separately from supervised split leakage.

## Targets and captions: what is and is not leakage

Targets are OCR values normalized to fixed units and averaged across rows/beats of a still, then log-scaled with statistics fitted on the training source. Measured values and report captions are supervision, not directly concatenated into vision tokens. Training on several correlated outputs is legitimate when none is an input and patients are separated. Correlated labels are not independent validation endpoints, however: Vmax/MaxPG or VTI-derived quantities can make several apparent successes reflect one measurement. Per-still averaging also means the exact algebra of a single beat need not hold between averages.

Full/Doppler caption selection now follows the presence of clip/still inputs. That fixes the prior scope bug. It remains coarse: any still routed to `hemo` can supervise a template containing RVSP, RAP and E/e′, and an aortic still can activate multiple aortic report statements. This is weak study-level supervision, not proof that each selected still contains the evidence for every statement. Do not describe each association as a directly measured physiology result. Use target-specific modality requirements and separately report partially supported captions. No new clinical severity thresholds are proposed here.

## Acceptance gate before research enablement

The Notion page first targets measured-status AUROC near 0.5, then specifies **AUROC ≤0.6** in its experiment plan. Repository documentation lists a measured-status linear probe, an overlay-only regression probe, and clean evaluation on unmeasured stills, explicitly as unfinished. There is no implemented gate artifact or empirical pass result. Default-off is containment, not a scientific pass.

Require all of the following for each enabled vendor/mode/target stratum. Numerical extensions below are proposed technical audit tolerances, not clinical cutoffs or validated clinical performance thresholds.

| Gate | Explicit acceptance criterion |
|---|---|
| Input and cohort lineage | Zero unknown/conflicting patient assignments, cross-split patients or duplicate-acquisition pairs. All training, tuning and audit assets have verified provenance and immutable digests. No OCR/report-derived feature or target alias may enter model inputs. Independently assigned tags work on unmeasured stills. |
| Sanitization qualification | All synthetic leakage contracts pass without expected-failure exemptions. No readable target digits or recoverable operator caliper/trace remains in the blinded, locked real-image audit sample. Record sample size and patient-clustered uncertainty; insufficient coverage leaves that stratum disabled. Audit waveform preservation separately so deleting useful content cannot count as success. |
| Measured-status discrimination | On matched, patient-disjoint held-out images/tokens, the 95% confidence interval must lie within [0.40, 0.60], covering both prediction orientations. This strengthens the design's ≤0.6 point threshold. Require the same for every prespecified vendor/mode stratum with sufficient precision. Use patient-level bootstrap and simultaneous or multiplicity-adjusted intervals for the planned family of tests. A wide interval or an underpowered stratum is inconclusive, not a pass. |
| Residual target information | On processed residual-overlay-only and mask-geometry-only inputs, upper 95% bounds must show no more than 5% relative MAE improvement over a training-fitted constant baseline and R² no greater than 0.05. Include patient-level label permutations and an unsanitized overlay positive control to show probe sensitivity. These proposed small-effect bounds must be frozen before testing. |
| Counterfactual overlays | With identical underlying spectra, randomize digits/caliper locations independently of physiology. The 95% upper bound on mean absolute prediction shift must be ≤0.05 training-target SD on the log-target scale. Use matched clean images plus synthetic overlays or real pre/post annotation pairs. Predictions must follow preserved waveform/calibration changes, not arbitrary glyph changes. Rescale the same waveform and update physical pixel spacing consistently: predictions should remain invariant to display pixel height when the physical velocities are unchanged. Also inspect tail changes and individual failures. |
| Genuine inference | Locked, genuinely unmeasured, patient-disjoint evaluation runs the same preprocessing/routing/feature availability as intended inference. For any claim of image-derived utility, paired confidence intervals must establish improvement over a metadata-only baseline. Any claimed added benefit over EchoNet must also exceed EchoNet-only performance. Report error, calibration, coverage and abstentions by vendor/mode/target; no clinical-accuracy claim follows from this audit gate alone. |
| Enforced approval | A reviewed machine-readable gate record binds the exact configuration, split, cache, preprocessing and upstream models; the training entry point fails closed if it is absent, stale or failed. All variants, including A0/A1 and optional EchoNet inputs, are covered. Only then request Robert's approval for research training. |

A measured-status probe alone is insufficient: it may learn real differences in case mix, and an uninformative linear probe does not exclude a nonlinear target shortcut. Match vendor, mode, acquisition conditions and, where possible, physiology or within-study pairs; use frozen linear and prespecified nonlinear probes. Keep all repeated images of a patient in one partition. Feature attribution can guide inspection, but empirical interventions and negative controls are necessary. This is consistent with experimental shortcut-learning work such as [Boland et al., MIDL 2024](https://proceedings.mlr.press/v250/boland24a.html).

## Work requiring governed MHI access and separate approval

1. Inventory measured AND unmeasured stills, OCR failures, vendor/layout/mode/year, calibration availability and duplicate acquisitions. Reproduce the 16%/75% label-overlap calculation with denominators and patient-level intervals; measure value-box overlap separately. Verify all patient joins and reserve a temporal/vendor holdout without patient overlap.
2. Have blinded reviewers annotate text/value boxes, grey/white/tinted calipers, VTI traces and residual artifacts before and after masking. Review a locked sample enriched for Philips and spectral-overlap cases, reporting both prevalence-weighted and enriched results. Do not publish identifiers or clinical images in repository artifacts.
3. After compute authorization, encode with the exact intended encoder/recipe and run the measured-status, residual-overlay, mask-only, metadata-only and counterfactual probes. Use raw-overlay positive controls and shuffled-label negative controls. Audit 2-frame and 16-frame cache variants independently if both are proposed.
4. Verify EchoNet input sanitization and model/fold lineage. Recompute contaminated or undocumented outputs; evaluate no-EchoNet, EchoNet-only, scalars-only, heat-map-only and combined arms. Ensure scalar-free heads actually receive no scalars.
5. Build a clean measurement-head evaluation with independent waveform-specific adjudication where feasible. Linked report values are useful secondary references but may summarize another beat/window or be copied from the same sonographer measurement; they are not automatically an independent gold standard. Distinguish same-acquisition unmeasured exports from independently acquired unmeasured scans.
6. Freeze preprocessing, probe selection, target families, margins and exclusions using development/validation data. Run the locked test once. Failed gates require a new development cycle and an untouched confirmation sample, not repeated tuning on the failed test.

## Reproduction and interpretation

Run from this checkout in a CPU Python environment with NumPy, PyTorch, pandas, OpenCV, pytest and the repository's test dependencies:

```sh
python -m tools.radar_still_leakage_audit --out /absolute/synthetic-output-directory
python -m pytest tests/datasets/test_still_leakage_audit.py tests/data/test_still_leakage_split_audit.py -q -rx
python -m pytest tests/datasets/test_still_leakage_audit.py tests/data/test_still_leakage_split_audit.py --runxfail -q
```

The last command deliberately exposes unmet safety contracts as test failures. Strict `xfail` annotations are a tracking mechanism: a green default pytest summary with expected failures does **not** authorize the stream. Passing observation tests demonstrate the counterexamples; passing positive controls show that the harness can recognize successful removal or rejection. The synthetic footprint classifier uses no box coordinates. Recovering the box bounding rectangle is a separate paired-difference analysis; the real-image probe must operate without a paired clean image or privileged annotation geometry unless explicitly evaluating a paired or mask-only control.

Executed verification: **66 passed, 11 strict expected failures, and 11 subtests passed** across nine focused modules, in two complementary runs. This includes the existing tiny CPU training/evaluation test, two-process CPU head-gradient test, routing, captions, manifest, preprocessing and the new audit tests. Running the two new audit modules with `--runxfail` produced **11 failures and 15 passes**, exposing precisely the unresolved contracts above. The ordinary passing count is not a leakage clearance. The 11 failure cases cover five pixel/footprint cases, two conditioning cases, two cache-provenance cases and two patient-identity cases. Existing warnings concern a timm import deprecation and torch.load in the synthetic distributed test. Environment: Python 3.12.8, PyTorch 2.5.1, NumPy 2.5.4, pandas 3.1.1, OpenCV 5.0.0.93 and pytest 9.2.0. No hosted CI result is claimed.

Execution results and environment versions are recorded with the companion audit outputs. This audit adds tests and a proposed qualification protocol, not a production fix or a real-data leakage clearance.
